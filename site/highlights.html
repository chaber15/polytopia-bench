Top three games

The single games with the biggest share of points. Each map is that game's final turn as the model saw it, rebuilt in the real game from the log.

How it works: a plugin inside the Steam game gives the model the game's own legal moves as tools; the game decides every rule, battle and score. Perfection mode, 30 turns, Small 14×14 Lakes map, vs 2 Hard CPUs. Each turn is a fresh session; the model's only memory is a 400-word note to itself. Medium reasoning effort for every model.
