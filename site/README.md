# Results site and highlights graphic

- `index.html`: the interactive results page (sortable leaderboard, every game with its final map and score race). Static; open it in a browser. Pushes to `main` that touch `site/` publish it to https://chaber15.github.io/polytopia-bench/ (`.github/workflows/pages.yml`).
- `highlights.html`: the one-page summary graphic. `./render.sh` turns it into `highlights.png` (2x, for posting) and `highlights.pdf` with headless Chrome.
- `data.js`: every headline game's result, score per turn and final map. Generated by `python3 site/build_data.py` from the game logs in `harness/logs/`; edit the model list there.
- `polymap.js`: draws a logged map as low-poly isometric tiles. No game art is used.
- `diorama.js`: the header art, a small four-tribe island (drawn with `polymap.js`) with a unit standing in each territory.
- `img/` (not in git): game art © Midjiwan. The unit sprites for the header, and `game-<log>.png`, in-game pictures of the top games' final turns. If a file is missing, the pages draw that part themselves.

To picture a game's final turn in the real game: start any single-player game on the same map size, then `POST /stage` with `{"state": <the log's last turn_start state>, "tribes": {"1": "Imperius", ...}}`. The plugin rebuilds the map, cities, units and the model's fog from the log and reloads. `POST /camera {"zoom": 0.3, "hideUI": true}` frames the whole 14×14 map for a screenshot.
